Production DevOps Tool Stack
=============================
A typical Jenkins agent includes:

| Tool          | Purpose                                  |
| ------------- | ---------------------------------------- |
| Git           | Clone repositories                       |
| Java          | Run Jenkins remoting & Java applications |
| Maven         | Build Java projects                      |
| Docker CLI    | Build and push images                    |
| kubectl       | Deploy to Kubernetes                     |
| Helm          | Helm chart deployments                   |
| AWS CLI       | AWS operations                           |
| Terraform     | Infrastructure provisioning              |
| Node.js       | Frontend builds                          |
| Python        | Automation scripts                       |
| Trivy         | Container image scanning                 |
| Sonar Scanner | Static code analysis                     |
